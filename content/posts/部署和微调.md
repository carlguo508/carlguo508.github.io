## 本地推理部署

在开始微调之前，先在本地用 Ollama 部署了 Qwen2.5，验证模型可以正常运行。

**用 Python requests 提问**

Ollama 默认在 `localhost:11434` 开一个 API server，有两种调用方式：
可以直接从terminal提问

原生 Ollama API：

```python
import requests

url = "http://localhost:11434/api/chat"
payload = {
    "model": "qwen2.5",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": False
}
response = requests.post(url, json=payload)
print(response.json()["message"]["content"])
```

## 微调

### 环境准备

**机器选择：vast.ai 租用 RTX 3090**

- 平台：[vast.ai](https://vast.ai/)
- GPU：1x RTX 3090，24GB VRAM
- 价格：约 $0.13–0.16/hr
- Template：选 **PyTorch (Vast)**，已预装 PyTorch 和 CUDA
- Container Size：调到 **40GB**（模型文件本身 6-7GB，需要留够空间）

**SSH 连接**

vast.ai 使用 SSH key 认证，不支持密码登录。

```bash
# 查看本地是否已有 SSH key
cat ~/.ssh/id_rsa.pub

# 没有则生成
ssh-keygen -t rsa -b 4096

# 连接时指定 key 文件
ssh -p <port> root@<ip> -i ~/.ssh/id_rsa
```

> **坑**：直接跑 SSH 命令会报 `Permission denied (publickey)`，需要在 vast.ai 的 instance 管理页面上传公钥，并在连接命令里加 `-i ~/.ssh/id_rsa` 显式指定 key 路径。

---

### HuggingFace 准备

1. 在 [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) 创建 **Read** 类型的 token（不需要 Fine-grained）
2. 申请 Llama-3.2-3B-Instruct 的访问权限（gated model，需要填表，通常几分钟批准）
3. 在 GPU 机器上登录：

```bash
python -c "from huggingface_hub import login; login(token='hf_xxx')"
```

> **坑 1**：`huggingface-cli` 命令在这台机器上没有加入 PATH，直接用会报 `command not found`。改用 `python -c` 调用 Python 函数绕过。

> **坑 2**：在 Mac 本地跑 merge 脚本也需要登录 HuggingFace，否则下载 base model 时会报 `401 Unauthorized`。

### 训练脚本

使用 QLoRA（4-bit 量化 + LoRA），数据集为 `tatsu-lab/alpaca` 前 500 条。

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig
from peft import LoraConfig, get_peft_model
from trl import SFTTrainer, SFTConfig
from datasets import load_dataset
import torch

model_name = "meta-llama/Llama-3.2-3B-Instruct"

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16,
)

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    quantization_config=bnb_config,
    device_map="auto",
)
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token

lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
)

dataset = load_dataset("tatsu-lab/alpaca", split="train[:500]")

trainer = SFTTrainer(
    model=model,
    train_dataset=dataset,
    peft_config=lora_config,
    args=SFTConfig(
        output_dir="./qlora-output",
        num_train_epochs=1,
        per_device_train_batch_size=4,
        gradient_accumulation_steps=4,
        learning_rate=2e-4,
        bf16=True,
        logging_steps=10,
        save_strategy="epoch",
    ),
)

trainer.train()
trainer.save_model("./qlora-output/final")
```

训练时间：约 20-30 分钟，花费约 $1 以内。

### 下载训练结果到本地

训练完成后，在 **Mac 本地** terminal 运行：

```bash
# 直接下载
scp -P <port> -r root@<ip>:~/qlora-output ./my-model

# 或者先压缩再传（文件大时更快）
# 在 GPU 机器上
tar -czf qlora-output.tar.gz qlora-output/

# 在 Mac 上
scp -P <port> root@<ip>:~/qlora-output.tar.gz ./
tar -xzf qlora-output.tar.gz
```

下载完成后立即删除 instance（点垃圾桶图标），避免继续计费。Stop 不够，必须 Delete。

### 合并 LoRA Adapter 到 Base Model

LoRA 训练出来的是 adapter 权重（很小），需要合并回 base model 才能独立使用。

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer

base_model_name = "meta-llama/Llama-3.2-3B-Instruct"
adapter_path = "./my-model/final"   # 注意是 final 子目录
output_path = "./merged-model"

model = AutoModelForCausalLM.from_pretrained(base_model_name)
model = PeftModel.from_pretrained(model, adapter_path)
model = model.merge_and_unload()

model.save_pretrained(output_path)
tokenizer = AutoTokenizer.from_pretrained(base_model_name)
tokenizer.save_pretrained(output_path)
```

> **坑**：adapter 文件在 `./my-model/final` 子目录里，不是 `./my-model`，路径写错会报 `Can't find 'adapter_config.json'`。

---

### 转换为 GGUF 格式

用 llama.cpp 把合并后的模型转成 GGUF，才能被 Ollama 加载。

```bash
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
pip install -r requirements.txt

python convert_hf_to_gguf.py ../merged-model \
    --outfile ../my-lora-model.gguf \
    --vocab-type bpe
```

> **坑**：Llama 3 使用 BPE tokenizer，转换时必须加 `--vocab-type bpe`，否则报 `TypeError: Llama 3 must be converted with BpeVocab`。

---

### 用 Ollama 加载并运行

```bash
# 创建 Modelfile
cat > Modelfile << 'EOF'
FROM ./my-lora-model.gguf
PARAMETER temperature 0.7
PARAMETER stop "<|eot_id|>"
PARAMETER stop "<|end_of_text|>"
EOF

# 注册模型
ollama create my-lora -f Modelfile

# 运行
ollama run my-lora
```

> **坑**：不加 stop token 的话模型会一直重复输出，不知道何时停止。Llama 3 的结束符是 `<|eot_id|>` 和 `<|end_of_text|>`，需要在 Modelfile 里显式配置。
