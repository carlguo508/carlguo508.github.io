# Personal Blog Design

## Overview
Personal website/blog using Hugo and GitHub Pages.

- **URL:** https://carlguo508.github.io/
- **Theme:** PaperMod (minimal/clean)
- **Hosting:** GitHub Pages via GitHub Actions

## Content Structure
- `content/posts/tech/` - technical posts
- `content/posts/personal/` - life/thoughts
- Tags for cross-cutting topics

## Features
- Auto dark/light mode
- Reading time on posts
- Code copy buttons
- Search, archives, tags pages
- Simple nav: Posts, Tags, Archives, About

## Deployment
- Push to `main` triggers GitHub Actions
- Hugo builds to `public/`
- Deployed to GitHub Pages automatically
